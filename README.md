# koeminer

Приложение для Windows и macOS: при добавлении карточки через Yomitan открывает окно выбора предложения из [Sentence Search](https://sentencesearch.neocities.org/). Можно прослушать аудио, выбрать пример, добавить без примера или отменить создание карточки.

Готовые сборки: [скачать последнюю версию](https://github.com/pmcwalrus/koeminer/releases/latest). Выберите Windows x64, macOS Apple Silicon или macOS Intel. Распакуйте архив целиком. Сборки не подписаны цифровой подписью.

## Картинки (v0.2.0)

В настройках типа заметки назначьте **«Поле картинки»**, например `Picture`. Добавьте это поле в формат заметки Yomitan и `{{Picture}}` в шаблон Anki. Если поле не назначено, прежний сценарий выбора предложения остаётся без изменений.

В окне добавления появится вкладка **«Картинки»**. Она ищет 10 изображений в Wikimedia Commons по слову карточки. Запрос можно изменить независимо от поиска предложений, например ввести английский перевод. Выберите предложение и/или картинку и нажмите **«Создать карточку»**. Можно убрать любой выбор; без выбранной картинки существующее содержимое поля сохраняется.

Картинки скачиваются в локальный кэш, проверяются и сохраняются в Anki как JPEG (до 1280 пикселей по большей стороне). В поле добавляется изображение и подпись с автором, лицензией и ссылкой на источник. API-ключ не требуется. Если источник нашёл меньше 10 изображений, показываются доступные; недоступные файлы отмечаются в сетке. Поиск Commons не гарантирует подходящие результаты для каждого слова.

## Локальный запуск

Готовая сборка Windows: `dist/koeminer/koeminer.exe`. Переносите всю папку `koeminer`, а не один exe. Либо запустите `start-koeminer.cmd`.

Из исходников (Python 3.14):

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py
```

Кнопка «Попробовать поиск и аудио» работает без Anki. Первый поиск загружает текстовую базу сайта (45 431 запись на момент разработки). Аудио загружается только при прослушивании или выборе. База и выбранное аудио кэшируются в пользовательском каталоге приложения; данные сайта не включаются в дистрибутив.

## Подключение Yomitan

1. Запустите Anki с [AnkiConnect](https://ankiweb.net/shared/info/2055492159).
2. В koeminer откройте «Настройки» → «Загрузить типы и поля из Anki».
3. Выберите **тот же тип заметки**, который используется в Yomitan. Назначьте поле слова/кандзи, предложения и аудио. Перевод необязателен. Нажмите «Сохранить настройки». Для каждого типа заметки настройки сохраняются отдельно; сохраняйте перед переключением типа.
4. Убедитесь, что эти поля существуют в Anki и включены в формат карточки Yomitan. Для слова используйте `{expression}`, для кандзи — `{character}`. Поля выбранного предложения и его аудио можно оставить пустыми в Yomitan.
5. Добавьте поля в шаблон карточки Anki, например `{{Sentence}}` и `{{SentenceAudio}}`, чтобы видеть текст и слышать запись при повторении.
6. В расширенных настройках Yomitan измените адрес AnkiConnect с `http://127.0.0.1:8765` на **`http://127.0.0.1:8766`**. Сам AnkiConnect продолжает работать на 8765. При использовании API-ключа укажите один и тот же ключ в AnkiConnect, Yomitan и koeminer.
7. Нажмите **+** в Yomitan. Выберите предложение в появившемся окне. После подтверждения создаётся одна заметка с данными Yomitan и выбранным примером.

Аудио сохраняется в медиатеке Anki как `[sound:koeminer_….mp3]` и доступно офлайн и при синхронизации медиа. По умолчанию назначенные поля заменяются; режим добавления сохраняет их прежний текст. Остальные поля, теги и медиа Yomitan сохраняются.

Закрытие главного окна сворачивает программу в трей, если он доступен. Для завершения выберите «Выйти» в меню значка. Чтобы вернуться к прямой работе Yomitan с Anki, восстановите адрес 8765.

## Ограничения первой версии

- Обычное одиночное добавление `addNote`. Массовое создание `addNotes` и создание внутри `multi` возвращают явную ошибку; массовый импорт выполняйте напрямую через AnkiConnect.
- Один выбор одновременно, время ожидания — 10 минут. Отмена не создаёт заметку. При ошибке загрузки аудио окно остаётся открытым.
- Поиск по буквальному вхождению, короткие предложения первыми, до 150 результатов. Автоматического приведения спряжений к начальной форме нет; запрос можно изменить вручную.
- Доступность отдельных аудиозаписей зависит от Sentence Search. Никакой массовой загрузки аудио.
- При обрыве связи непосредственно после отправки `addNote` результат может быть неопределённым: проверьте Anki перед повторным нажатием. Автоматически повторять создание приложение не будет.
- macOS-сборки пока без Developer ID и notarization. Проверка на настоящем Mac и в настоящем Yomitan должна выполняться отдельно от автоматических тестов протокола.
- API-ключ, если задан, хранится в локальном `settings.json`; не публикуйте этот файл.

## Разработка и сборки

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
python scripts/build.py
```

Стек: Python, PySide6/Qt Multimedia, HTTPX; локальный HTTP-сервер из стандартной библиотеки. Слушает только loopback. Браузерные запросы разрешены от расширений, обычные веб-страницы блокируются. Поддерживается старый формат AnkiConnect v2, используемый Yomitan, и современный v6. Поиск картинок использует [MediaWiki Search API](https://www.mediawiki.org/wiki/API:Search) и [Imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo).

`.github/workflows/build.yml` запускает тесты и сборки Windows x64, macOS ARM64 и x64. При push тега `v*` после успешной сборки всех платформ автоматически публикуется GitHub Release с ZIP-архивами и SHA-256. Заметки релиза берутся из `RELEASE_NOTES.md`.

Для изолированного запуска: `python run.py --data-dir .dev --preview`.

Источники протоколов: [Yomitan](https://github.com/yomidevs/yomitan/blob/master/ext/js/comm/anki-connect.js), [AnkiConnect](https://github.com/FooSoft/anki-connect), [Sentence Search](https://sentencesearch.neocities.org/script/search.js).
