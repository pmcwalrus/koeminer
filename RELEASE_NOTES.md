koeminer 0.3.0 для Windows и macOS.

### Изменения

- По 10 картинок из Яндекса и Wikimedia Commons без API-ключей и подписок.
- Источники расположены рядом в двух столбцах с независимой прокруткой.
- Кнопка «Загрузить ещё» добавляет следующую порцию результатов, повторные изображения отфильтровываются.
- Поиск картинок начинается параллельно выбору аудио.
- Настраиваемое поле выделенного текста для поиска картинок; при пустом или отсутствующем поле используется слово карточки.
- Простой системный интерфейс, изменяемый размер окна и прокрутка содержимого.
- Выбор аудио переключает на картинки, выбор картинки — на аудио. После выбора обоих окно закрывается автоматически.
- В поле картинки записывается только изображение без подписи об источнике.

### Поиск по выделенному тексту Yomitan

1. Добавьте в тип заметки Anki поле `popup_selection_text` или используйте существующее отдельное поле.
2. В настройках формата карточки Yomitan назначьте ему маркер `{popup-selection-text}`.
3. В koeminer укажите имя этого поля в «Поле выделенного текста для картинок» и сохраните настройки.
4. Выделите текст внутри окна Yomitan перед нажатием «+».

### Скачать

- Windows x64: распакуйте `koeminer-windows-x64.zip` целиком и запустите `koeminer/koeminer.exe`.
- macOS Apple Silicon: `koeminer-macos-arm64.zip`.
- macOS Intel: `koeminer-macos-x64.zip`.

На macOS перенесите `koeminer.app` в Applications. Сборки не подписаны; macOS может потребовать разрешения запуска в настройках безопасности. Контрольные суммы архивов — в `SHA256SUMS.txt`.

### Проверки и ограничения

Локально прошли 32 автоматических теста. На Windows проверены реальные результаты обоих источников, загрузка изображений и следующая порция поиска. Перед публикацией GitHub Actions запускает тесты и сборку для каждой платформы. Ручная проверка на физическом Mac не выполнена.

Интеграция Яндекса неофициальная: капча или изменение сайта могут временно нарушить поиск. Загружаются копии картинок с серверов Яндекса, их разрешение может быть ниже оригинала. Wikimedia продолжает работать независимо.
