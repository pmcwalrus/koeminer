koeminer 0.4.0 для Windows и macOS.

### Изменения

- Дополнительные теги через запятую в настройках каждого типа заметки. Теги Yomitan сохраняются; повторяющиеся теги не добавляются.
- Поля ввода и выпадающие списки настроек меняют ширину вместе с окном, включая узкие окна.
- В правом нижнем углу показаны текущая версия и последняя версия из GitHub Releases; ссылка открывает страницу загрузки. Проверка GitHub работает в фоне и не мешает запуску без сети.

### Скачать

- Windows x64: распакуйте `koeminer-windows-x64.zip` целиком и запустите `koeminer/koeminer.exe`.
- macOS Apple Silicon: `koeminer-macos-arm64.zip`.
- macOS Intel: `koeminer-macos-x64.zip`.

На macOS перенесите `koeminer.app` в Applications. Сборки не подписаны; macOS может потребовать разрешения запуска в настройках безопасности. Контрольные суммы архивов — в `SHA256SUMS.txt`.

### Проверки и ограничения

Локально прошли 44 автоматических теста. GitHub Actions запускает тесты и собирает архивы для каждой платформы перед публикацией. Ручная проверка на физических Windows и Mac с настоящими Anki и Yomitan не выполнена.

Интеграция с Яндексом неофициальная: капча или изменение сайта могут временно нарушить поиск картинок. Wikimedia Commons продолжает работать независимо.
