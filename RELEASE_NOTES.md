Первая версия koeminer для Windows и macOS.

- Выбор предложения Sentence Search во всплывающем окне при добавлении карточки через Yomitan.
- Прослушивание аудио перед выбором и сохранение MP3 в медиатеке Anki.
- Настройка полей слова/кандзи, предложения, аудио и перевода для каждого типа заметки.
- Режим добавления к существующим полям, добавление без примера и отмена.
- Пробный поиск без Anki, локальный кэш, работа в трее.

### Скачать и запустить

- **Windows x64:** распакуйте `koeminer-windows-x64.zip` целиком и запустите `koeminer/koeminer.exe`.
- **macOS Apple Silicon:** `koeminer-macos-arm64.zip`.
- **macOS Intel:** `koeminer-macos-x64.zip`.

Для macOS распакуйте архив и перенесите `koeminer.app` в Applications. Сборки не подписаны Developer ID и не прошли notarization; macOS может потребовать разрешения запуска в настройках безопасности. Windows-сборка также без цифровой подписи.

### Подключение

Запустите Anki с AnkiConnect. В koeminer загрузите типы заметок и назначьте поля. В Yomitan замените адрес AnkiConnect на `http://127.0.0.1:8766`; настоящий AnkiConnect остаётся на `http://127.0.0.1:8765`. Подробности — в README репозитория.

### Проверки и ограничения

Автоматические тесты проверяют протокол, сохранение полей, отмену и путь от HTTP-запроса до окна выбора. На Windows дополнительно проверены поиск по реальной базе и воспроизведение MP3. Ручная проверка с настоящим Yomitan/Anki и на физическом Mac ещё не выполнена.

Поддерживается одиночное добавление карточек. Поиск — буквальное вхождение, до 150 результатов. Доступность аудио зависит от сайта. Для проверки скачанных архивов приложен `SHA256SUMS.txt`.
