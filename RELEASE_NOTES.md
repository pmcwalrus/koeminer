koeminer 0.4.2 для Windows и macOS.

### Исправления

- Проверка последней версии больше не использует ограниченный по частоте GitHub API. Приложение определяет номер версии по публичному перенаправлению на последний релиз; при ошибке её причина отображается во всплывающей подсказке.
- Подписи полей в настройках расположены слева при обычной ширине окна. В узком окне подписи переносятся над полями, чтобы сохранить доступность элементов управления.

### Скачать

- Windows x64: распакуйте `koeminer-windows-x64.zip` целиком и запустите `koeminer/koeminer.exe`.
- macOS Apple Silicon: `koeminer-macos-arm64.zip`.
- macOS Intel: `koeminer-macos-x64.zip`.

На macOS перенесите `koeminer.app` в Applications. Сборки не подписаны; macOS может потребовать разрешения запуска в настройках безопасности. Контрольные суммы архивов — в `SHA256SUMS.txt`.

### Проверки и ограничения

Локально прошли 47 автоматических тестов. GitHub Actions запускает тесты и собирает архивы для каждой платформы перед публикацией. Ручная проверка на физических Windows и Mac с настоящими Anki и Yomitan не выполнена.
