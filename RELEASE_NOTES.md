koeminer 0.4.3 для Windows и macOS.

### Новое

- Сохранение всех сохранённых настроек приложения в файл `.koe` и восстановление из него во вкладке «Настройки».
- При восстановлении файл проверяется, замена настроек требует подтверждения, а при сбое запуска сервера прежний конфиг сохраняется.
- Копия включает настройки всех типов заметок, порты и API-ключ AnkiConnect. **Ключ хранится в файле открытым текстом:** не публикуйте `.koe` и храните его в безопасном месте.

### Скачать

- Windows x64: распакуйте `koeminer-windows-x64.zip` целиком и запустите `koeminer/koeminer.exe`.
- macOS Apple Silicon: `koeminer-macos-arm64.zip`.
- macOS Intel: `koeminer-macos-x64.zip`.

На macOS перенесите `koeminer.app` в Applications. Сборки не подписаны; macOS может потребовать разрешения запуска в настройках безопасности. Контрольные суммы архивов — в `SHA256SUMS.txt`.

### Проверки и ограничения

Локально прошли 52 автоматических теста. GitHub Actions запускает тесты и собирает архивы для каждой платформы перед публикацией. Ручная проверка с настоящими Anki и Yomitan на физических Windows и Mac не выполнена.
